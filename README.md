# OutOfTower Wiki

OutOfTower 是一个《杀戮尖塔》开放式地图框架。内容模组通过 JSON 定义地图尺寸、节点、连线和事件池，通过普通 `AbstractEvent` 实现节点内容。

## 开始使用

* [创建自己的开放地图](https://github.com/petitioner0/OutOfTower/wiki/创建自己的开放地图)

完整示例工程也可以在主仓库的 [`examples/sample-content`](https://github.com/petitioner0/OutOfTower/tree/master/examples/sample-content) 中查看。

> OutOfTower 本身不提供默认地图。没有内容模组注册地图时，游戏继续使用原版地图。
